## Overview
**WhiteBox** is an innovation management platform developed and maintained at **ICT Authority's Innovation Department**. The platform facilitates innovator onboarding, idea submission, and programme management. I led the frontend revamp and full platform maintenance during 2025, resulting in a **32% increase in innovator intake**.

## What I Built / Improved
- **Frontend Revamp** — modernised the UI/UX with a clean, responsive design
- **Responsive Design** — fully mobile and cross-device compatible
- **Innovator Onboarding** — streamlined registration and navigation flows
- **Platform Maintenance** — bug fixes, performance tuning, feature enhancements
- **Server Configuration** — deployed on server with backup database setup
- **Documentation** — full user manual and maintenance guide for business continuity

## Impact
```
✅ 32% increase in innovator intake and onboarding
✅ Improved cross-device compatibility (mobile, tablet, desktop)
✅ Enhanced user experience — faster navigation and reduced friction
✅ Server configured with backup database for business continuity
✅ Full user manual and technical documentation produced
```
